# Target information architecture

## Persistent shell

- Desktop: 272 px collapsible sidebar and 72 px sticky top bar.
- Tablet: compact icon rail that can expand.
- Mobile: top-bar menu button and modal navigation drawer; no reserved rail width.
- Main content: warm canvas, max-width 1,680 px and responsive 16/24/32 px gutters.

## Navigation

1. Overview: Dashboard
2. Commerce: Products, Categories, Inventory, Stock movements, Stock counts, Orders
3. Relationships & supply: Customers, Complaints, Suppliers, Purchase orders
4. Growth & finance: Campaigns, Reports, Insights, Segments, Loyalty rewards, Reconciliation, Channels
5. People & governance: Staff, Attendance, Payroll, Users, Roles, Audit log, Settings, Localization
6. Platform & review: Automation, Platform, Demo & UAT

Subroutes such as receiving, transfers, SLA policy, report schedules, edit and detail pages remain contextual links from their parent module.

## Page archetypes

- Overview: header, filters, KPI strip, primary chart, action queue and activity table.
- List: compact header, toolbar, optional summary, data table and pagination.
- Detail: summary header, primary record, actions/timeline and supporting facts.
- Form/command: grouped form sections plus a contextual summary/action rail where useful.
- Analytics: filters, metrics, chart/table and optional configuration drawer.
- Settings/control: status summary, grouped policies, explicit mock/live boundary and confirmations.
