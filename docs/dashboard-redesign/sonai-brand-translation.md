# Sonai brand translation

## Brand signal

The live storefront uses the Sonai wordmark, deep burgundy announcement bar, editorial product photography, cream/white structure, black operational controls and restrained serif display type. The admin should feel connected without becoming a marketing page.

## Translation

- Keep the existing cream `#F8F6F1`, charcoal `#2C2C2C`, white, gold `#C4A574`, muted teal `#5B8A8E` and warm brown `#8B6F47` foundations.
- Use charcoal for primary controls and sidebar structure; use gold as a highlight rather than small text.
- Use warm brown for accessible accent copy and muted teal for focus, information and secondary visualization.
- Retain Georgia-style serif headings selectively; use a system sans stack for controls, tables and body copy.
- Use the visible spelling `Sonai` to match the explicit task and storefront. Internal package, schema and repository names remain unchanged.
- Avoid decorative patterns, large photography and promotional treatments inside operational workspaces.
