Desktop uses a responsive 12-column composition; tablet collapses to two columns; mobile stacks panels, uses the filter drawer and converts the recent-order table to labeled cards. Server rendering remains the default and only charts, the map, tabs, drawers and table controls cross a Client Component boundary.
