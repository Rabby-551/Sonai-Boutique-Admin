# Locked upper dashboard section

## Protected composition

The `/dashboard` page heading (`Business intelligence · FR-182`, `Operations overview`, and its scoped summary) plus `DashboardBrandBanner` are the visual baseline. Preserve their order, campaign image, copy placement, rounded featured surface, warm canvas, and maroon/ivory/gold hierarchy.

Permitted changes are limited to localized copy, semantic labels, responsive typography/stacking, image loading, contrast, reduced-motion-aware entrance, and other accessibility corrections. New intelligence begins below the banner.

## Regression guard

Desktop and mobile dashboard baselines must include the heading and full banner. Any material image, crop, layout, color, or composition change requires explicit stakeholder approval before updating those baselines.
