## Shared state requirements

- Lists keep search, filters, sort and pagination in the URL.
- Detail and command routes keep current permission, version, confirmation and audit behavior.
- Loading, empty, error, no-result, permission and success states use shared visual primitives without changing data ownership.
- Tables remain primary on desktop; selected dense tables gain mobile record-card alternatives rather than silently hiding required values.
