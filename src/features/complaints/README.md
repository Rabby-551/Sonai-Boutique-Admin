# Complaints

Complaints, queries, and support requests share an auditable case workflow. Assignment is separate from acknowledgement. Server actions validate every transition and create timeline events; client controls only expose permitted commands.

Customer-update notes record fictional notification events without sending messages. Attachment records are safe metadata only and accept JPEG, PNG, or PDF metadata up to 5 MB; binary upload and permanent storage remain external boundaries.
