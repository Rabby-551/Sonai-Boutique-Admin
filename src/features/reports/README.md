# Reports

Reports calculate sales, profit, inventory valuation, campaign, procurement, and payroll views directly from the unified validated store. Filters are URL-backed. CSV export uses the same result contract and neutralizes spreadsheet formula injection.

Current profit uses catalog cost snapshots already stored on order lines. Procurement costs do not revalue inventory automatically.
